# ELI5 — Explain Like I'm 5

把任何概念讲到五岁小孩能懂。核心不是「简化」，是**换锚点**：从对方已有的生活经验出发重建理解，而不是从术语出发往下稀释。

## 何时触发

- 用户明确要求 ELI5 / 大白话 / 通俗讲
- 用户对先前解释回复「没懂」「太抽象」「说人话」
- 概念解释连续两轮失败后的强制降档

## 解释规则

1. **类比先行**：先用一个生活类比把直觉立起来，再谈概念本身。类比要选用户世界里的东西（做饭、寄快递、班级管理、打电话），不要选另一个技术概念当类比。
2. **零术语首过**：第一段解释不允许出现任何领域术语；必须引用术语时，先用大白话定义它再使用。
3. **三档递进**：默认输出三档——
   - 🧒 **5 岁版**：一个类比 + 三句话
   - 🧑 **12 岁版**：类比展开 + 工作机制 + 一个具体例子
   - 🧑‍💻 **成人版**：完整机制 + 边界条件 + 与相邻概念的关系
   用户没指定档位时三档都给，让用户自己选停留深度。
4. **一个例子一个反例**：正向例子说清「是什么」，反例划清「不是什么」（例如解释哈希表：正向是「按名字首字母归档的电话簿」，反例是「不是按存放顺序找的抽屉」）。
5. **检查理解**：结尾抛一个 One-shot 小问题（用刚讲的类比回答），答对才算过。

## 禁止

- 用术语解释术语（「指针是指向内存地址的变量」❌）
- 类比链超过一层（用 A 比 B，再用 B 比 C，用户会在第二层丢失）
- 省略反例（没有反例的类比必然过度泛化）
- 「就是这样，记住就行」——记不住的，能记住的只有锚点
