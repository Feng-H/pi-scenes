description: 提交前自检——构建/测试/diff 审查/提交信息四步全过才允许 git commit

---
对即将提交的变更（$@，未指定则取当前暂存区/近期变更）执行四步自检，**逐步执行、禁止跳步、禁止合并步骤**：

1. **构建**：运行项目的构建/类型检查命令（无则跳过并说明）。失败 → 停止，报告错误。
2. **测试**：运行测试套件（或至少覆盖受影响文件的子集）。失败 → 停止，报告失败用例。
3. **Diff 审查**：逐文件读 diff，检查：误提交的调试代码、密钥/隐私数据、超出本次意图的无关变更、遗留 TODO。发现问题 → 列出并等用户决定。
4. **提交信息**：按项目惯例（查最近 git log 提炼格式）起草提交信息，给出后由用户确认执行 commit。

输出格式：每步一行 ✅/❌ + 证据（命令与关键输出摘要），四步全绿才进入提交流程。
