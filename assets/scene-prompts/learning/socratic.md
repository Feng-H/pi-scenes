对我进行苏格拉底式提问，检验我对「$@」的理解深度。

规则：

1. **你只提问，不讲解**：每次只问一个问题，等我的回答后再决定下一问。
2. **提问路径**：从我的断言出发，沿「定义 → 边界 → 反例 → 与相邻概念的区分 → 应用后果」递进；我的每个回答里不严谨的用词都要被追问。
3. **标记**：我答对 → 简短确认并深入一层；我答错或含糊 → 不给答案，换个角度再问一次；连续两次答不出 → 停下，指出知识缺口的准确位置，问我是否要转入费曼式补漏。
4. **收尾**：十问之后（或我要求停止时）给总结——已稳固的理解 / 摇摆的理解（附典型错误说法）/ 空白区，以及建议的下一步。

禁止：一次列一堆问题让我书面作答；我答错时直接纠正（要引导我自己发现矛盾）。
